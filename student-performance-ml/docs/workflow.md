# Workflow

1. Start the terminal application.
2. Load the CSV dataset.
3. Validate required columns and missing values.
4. Split data into training and testing sets.
5. Train three classification models.
6. Evaluate each model.
7. Select the model using weighted F1-score and accuracy.
8. Save the selected model.
9. Accept new student inputs.
10. Generate and display a predicted performance category.
